# Spike manuscript figures

The notebooks display the approved manuscript figures from the November 2026 release. Open a notebook in Jupyter to view its saved previews, or run its cells to verify and display the bundled images. Each image cell checks the SHA-256 digest of the corresponding PNG or SVG. Run Jupyter from this repository so the notebooks can locate their figure assets.
